# Design System — 今天吃啥(健康菜谱微信小程序)

> **方向修订(用户明确指示)**: 放弃旧「杂志编辑风(绿+纸感+衬线)」。参考用户提供的竞品截图(「吃啥有答案」),改为**暖橙食欲系菜谱风格**: 橙色主导航、奶油暖底、大圆角白卡、加粗黑标题 + 橙色强调、胶囊大按钮、亲和圆润。本文件为唯一视觉约束;源码中的旧绿色/纸感样式**已废弃**,仅作为内容与结构参考。

## 产品语境

- **产品**: 「今天吃啥」— 按手头食材找菜、按健康人群推荐菜谱的微信小程序。参赛作品,重视推荐可解释、健康信息有边界、离线可用。
- **平台**: 微信小程序(uni-app + Vue3),750rpx 设计稿宽(= 375px CSS)。橙色原生导航栏(白字标题)+ 原生 3-tab 底栏(选菜/推荐/我的)。
- **核心用户流转**: 首页选食材 → 匹配菜谱列表 → 菜谱详情(用料/营养/步骤/加本周计划)→ 本周计划 + 购物清单;旁路: 推荐页按 6 类健康人群浏览;我的页管档案/收藏/数据。
- **JTBD**: "家里有这些食材,今晚吃啥能兼顾家人的健康情况" — 帮决定、讲清推荐依据、落到买菜。
- **内容基调**: 20 道本地菜谱(家常/健身/婴儿辅食/老年/控糖/低脂),真实配图 3:2;38 种食材;6 类健康人群。文案克制、诚实(营养是估算、建议不替代医生、联网查询明示数据去向)。

## 品牌与视觉语言(新 · 暖橙食欲风 / Warm Appetite)

**关键词**: 暖橙、食欲感、亲和、圆润饱满、明快直接。

1. **色彩**(从参考截图提取)
   - 主橙 `#ED6A3C`(导航栏底、主按钮、选中态、强调文字),橙渐变按钮 `linear-gradient(90deg,#F5924E,#EA5F33)`
   - 奶油暖底 `#FAF1E6`(页面背景),更浅的 `#FDF6EE` 用于嵌套区域
   - 卡片白 `#FFFFFF`,大圆角 16-20px,暖橙调轻投影 `0 8 24 rgba(233,106,61,0.08)`
   - 暖黑正文 `#2B2018`(标题加粗),暖灰次要 `#8A7A6D`,弱化 `#B5A899`
   - 辅助浅橙卡 `#FFF3E4`(帮我决定类功能卡底)、浅橙描边 `#F5D8C2`
   - 功能彩色(参考截图三入口卡): 浅橙 `#FFF0DF`+橙字(选择食材)、浅绿 `#E8F3E2`+绿字 `#4C8B5E`(健康/精选)、浅蓝 `#E4F0FA`+蓝字 `#4A7FB5`(扩展/上传)
   - 语义色(保持可辨识但偏暖): 忌口/错误 `#E05A4E`,成功/已有 `#4C8B5E`,提醒/小贴士 `#ED6A3C`,在线扩展(ShowAPI)蓝 `#5B8DB8`
   - 分类圆点色(左侧食材栏): 蔬菜绿 `#7CB98E`、肉类红 `#E0705F`、蛋豆黄 `#E8B54D`、海鲜蓝 `#6FA8D8`、主食橙 `#E8955C`、菌菇棕 `#A9846B`、水果粉 `#E58BA2`、调味紫 `#9B8BC4`
2. **字体**(无衬线,加粗醒目)
   - 全站无衬线栈 `-apple-system,'PingFang SC','Microsoft YaHei',sans-serif`;**弃用衬线**
   - Hero 大标题 32-36px 加粗暖黑,重点词用主橙 + 粗下划线/笔触感短线强调(如「今天<橙>吃什么？</橙>」)
   - 区块标题 18-20px 加粗 + 左侧小彩圆点/图标;正文 13-14px;辅助 11-12px
   - 数字(匹配度/进度百分比)可用加重橙
3. **版式母题(全站复用)**
   - 大搜索胶囊: 白底胶囊,左「搜」字前缀,右侧内嵌橙色渐变「搜索」胶囊按钮
   - 功能引导卡: 浅橙渐变底大圆角卡 + 标题加粗 + 描述 + 右侧大号橙色渐变胶囊 CTA(「帮我选 1 道 >」)
   - 食材选择: **左侧竖向分类栏**(白底圆角竖条,彩圆点+分类名,选中橙字浅橙底) + 右侧两列白色胶囊食材卡(名称+彩图标+右侧橙描边「+」圆钮,选中变橙实心「✓」)
   - 底部粘液条: 「已选 N 种食材」+ 橙色渐变大胶囊 CTA(「查看能做啥」)
   - 菜谱卡: 白卡大圆角,顶部 3:2 圆角图 + 右上匹配度橙底白字小徽章,内容区加粗标题 + 暖灰 meta + 彩色药丸标签(低脂=浅绿、控糖=浅蓝、快手=浅橙…)
   - 编号步骤: 橙色圆形序号钮
   - callout: 浅色圆角条(左图标+文字),不再用左色条硬边
4. **间距/尺寸**: 页面左右 padding 16px;卡片间距 12-16px;卡片圆角 16-20px、按钮胶囊 999、食材卡胶囊 999;tab 页底部留 160rpx 避让底栏;按钮高 44-48px。
5. **动效**: 按压 scale(0.97);列表渐入上移 stagger;弹层 slide-up;进度条橙色渐变;收藏心跳。轻快、圆润。
6. **图标**: Lucide 线性描边(stroke 2),按语境着色(食材彩点、功能橙);**全站禁止 emoji 与 Unicode 伪图标字符**(项目硬规范 — 参考图的 emoji 一律用彩色 Lucide 图标等价表达)。

## 项目硬性要求

- 单位 rpx;模板容器 view/text/image(uni-app),设计稿输出 HTML 时可用 div/span/img 等价。
- 必须包含原生底栏模拟(tab 页): 白底圆角上沿,3 项(选菜/推荐/我的),未选暖灰 `#8A7A6D`、选中主橙 `#ED6A3C`。
- 健康/隐私声明文案必须保留(信息边界是参赛评审点),不得删除 callout 类内容。
- 菜谱图为 3:2 真实食物照片;在线菜谱(ShowAPI)无图,用蓝色系信息卡表达,不造假图。

## 本次任务基调

为 7 个页面出**重设计概念稿**: 全部采用上述暖橙食欲风替换旧绿色纸感;结构、内容、功能保持源码一致,视觉焕新;版式可大胆(大标题、饱满卡片、彩点分类),但色彩/字体/图标语言不得跳出本系统。
